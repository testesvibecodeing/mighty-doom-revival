O INFERNO ESTÁ ESPERANDO.

O patcher altera o endpoint do cliente, ajusta rede/TLS, recompila, alinha e assina o APK para conectar ao Revival Server.

Publicar seu APK neste site

  1. Na VPS, rode sudo ./scripts/install.sh — no final ele imprime um link temporário de upload.
  2. Abra o link no navegador e arraste o APK já patcheado. O link fica ativo por 24 horas.
  3. O botão de download do site passa a servir o APK automaticamente (com tamanho e SHA-256 reais).
  4. O instalador também imprime, logo abaixo, um link de cancelamento: abra-o para eliminar o upload na hora e ninguém substituir o seu APK.

O upload é opcional: sem APK publicado, o servidor do jogo funciona normalmente — só o download pelo site fica indisponível.

// FAQ

PERGUNTAS FREQUENTES

O status do servidor é real?

Sim. A página consulta /revival/health e /revival/apk no próprio domínio a cada 30 segundos e todos os números exibidos (jogadores, pacotes, eventos, uptime, latência, APK) vêm direto do servidor real.

Como o APK aparece para download?

Via link temporário de 24 horas impresso pelo scripts/install.sh. Depois de enviar, o download fica ativo em /download/mighty-doom-revival.apk. Para bloquear novos envios antes das 24h, use o link de cancelamento impresso junto.

Posso usar meu próprio domínio?

Sim. Informe o domínio no instalador da VPS e use o mesmo domínio no patcher do APK. O site é servido pelo próprio servidor, então tudo fica no mesmo domínio automaticamente.

Existe pagamento real?

Não. A proposta do Revival é usar somente moedas e recursos internos do jogo; IAP e anúncios respondem como desabilitados.
